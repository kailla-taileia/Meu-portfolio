# 💻 Portfólio Web

Este foi meu primeiro desafio pessoal após concluir os módulos de HTML e CSS.

## 📌 Sobre o projeto

O objetivo foi recriar um portfólio a partir de um modelo gerado por inteligência artificial, colocando em prática os conhecimentos adquiridos durante os estudos.

Recebi apenas a versão desktop como referência e, além disso, também desenvolvi a responsividade para adaptar o projeto a diferentes tamanhos de tela.

## 🚀 Tecnologias utilizadas

- HTML5
- CSS3

## 📚 Aprendizados

Com esse projeto, consegui aprimorar:

- Estruturação de páginas com HTML  
- Estilização com CSS  
- Organização de layout  
- Responsividade  

## 🎯 Próximos passos

Pretendo evoluir esse projeto utilizando JavaScript, adicionando funcionalidades como:

- Funcionamento de formulários  
- Interações dinâmicas
